# Gokulraj Portfolio — Final Deployment

Professional academic, AI research and innovation portfolio for G. Gokulraj.

## Deploy on GitHub Pages
1. Upload the contents of this folder to the repository root.
2. Commit to the default branch.
3. In GitHub: Settings → Pages → Deploy from a branch.
4. Select the repository branch and `/ (root)`.
5. Save and wait for the Pages build.

## Important
- Keep `assets/` and its subfolders in the same relative location.
- The portfolio is static and requires no build step.
- Resume: `assets/docs/G_Gokulraj_Resume.pdf`
- Profile photo: `assets/images/profile.jpg`
- Certificates: `assets/certificates/`
